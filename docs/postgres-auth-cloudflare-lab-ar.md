# تجربة PostgreSQL وBetter Auth وقياس Cloudflare

## نطاق آمن

أنشأنا مختبراً في `experiments/postgres-auth-lab/`، وربطنا النموذج التجريبي السابق بجداول Better Auth وقاعدة PostgreSQL فعلية محلية منفصلة، وبحسابات وكلمات مرور اختبارية فقط. قاعدة الاختبار محلية ومؤقتة، ويشترط الاختبار عنوان loopback واسم قاعدة محدداً ثم ينشئ مخططاً عشوائياً ويحذفه. أضفنا إجراء GitHub Actions بخدمة PostgreSQL مؤقتة؛ لا يستخدم سر Neon ولا ينشر التطبيق. **لم نغيّر Neon أو قاعدة الإنتاج ولم ننشر واجهات دخول.**

المختبر ليس مهايئ الإنتاج: يستخدم مخططاً مصغراً وصلاحيات واسعة، وليس سياسات RLS أو دور التطبيق المحدود أو مخطط الموظفين الحقيقي. ليس ربطاً بخادم النظام المنشور أو Neon، ولا يستخدم معرّف المؤسسة ورقم الموظف الحقيقيين. يتطلب التنفيذ الفعلي تصميماً واختباراً منفصلين لهوية طالب العملية والتحكم في الصلاحيات، وسياسات RLS، والتعامل مع الحسابات المشتركة وتغييرات العضوية، وسلامة التزامن على جميع المسارات، قبل أي تشغيل لموظفين.

## نتائج الاختبارات الفعلية

- اختبارات PostgreSQL + Better Auth المحلية نجحت: رفض محاولة عابرة للمؤسسات وحساب مشترك، وتراجع تحديث كلمة المرور والنسخة والجلسات والتدقيق عند حقن الفشل في كل مرحلة، وإلغاء جلسات Better Auth القديمة فعلياً مع رفض كلمة المرور القديمة وقبول الجديدة، مع الحفاظ على جلسة مستخدم المؤسسة الأخرى.
- إعادة ضبط متزامنة من طالبَي عملية مختلفين أكملت بزيادتين للنسخة؛ وأظهر اختبار قفل الصف أن تغيير العضوية المتعاون مع نفس القفل يُمنع مؤقتاً. لا يضمن هذا حماية أي مسار لا يلتزم بالقفل نفسه، ولا يغني عن قيود ومراجعة صلاحيات قاعدة البيانات.
- **اكتُشف سباق حقيقي:** عند إيقاف دخول Better Auth العادي بعد التحقق من كلمة المرور وقبل إنشاء الجلسة، ثم إعادة الضبط، استطاع إصدار جلسة قديمة بعد الإلغاء. إلغاء الجلسات وحده لا يكفي. أضفنا في المختبر وسيط دخول يقرأ النسخة قبل التحقق ويمنع تسليم ملف الارتباط حتى يسجل الجلسة تحت قفل مشترك ويتحقق من بقاء النسخة؛ وفاحصاً يرفض الجلسات بلا تسجيل أو بنسخة قديمة أو دون عضوية. نجح اختبار السباق بهذه الطريقة، واختبار رفض جلسة غير مسجلة حتى لو قبلها Better Auth مباشرة. **هذا الحل تجريبي فقط**، ولم نثبت شموله كل مسارات Better Auth أو سلامة ملفات الارتباط وCSRF في تطبيق ويب حقيقي؛ لا يجوز كشف واجهات Better Auth المباشرة.
- الطلبات التي بدأت قبل الإلغاء تحتاج سياسة تزامن خاصة؛ فحص الجلسة قبل الطلب لا يوقف تلقائياً عملية أُجيزت بالفعل. يلزم كذلك منع تعداد الحسابات، وحد المحاولات، وتسليم بيانات الدخول بأمان، ومراجعة حماية الجلسات والاعتمادات، ومعالجة الجلسات غير المسجلة بعد فشل الخادم.

## Cloudflare: فحص مُجهّز، ليس قياساً حقيقياً

أعددنا في `experiments/cloudflare-cpu-lab/` Worker مستقلاً لا يتصل بقاعدة البيانات ويجري إنشاء حساب وتسجيل دخول وهميين في الذاكرة. لا يتصل بمسارات التطبيق الفعلي ولا يختبر ضوابط PostgreSQL. يكون معطلاً افتراضياً: يتطلب تشغيله إعداداً صريحاً ومفتاحاً سرياً طويلاً؛ ويرفض الطلبات الأخرى قبل عمليات التجزئة. لا يوجد مسار منشور أو عنوان `workers.dev` أو معاينات في إعداده، ولا يوجد أي سر في المستودع. نجح اختبار الرفض والقبول في Node ومحاكي workerd المحلي. بناء Wrangler التجريبي `--dry-run` فقط: 1883.48 KiB غير مضغوط. **هذه ليست أرقام CPU حقيقية.**

قبل قياسه على Cloudflare الحقيقي يلزم إنشاء Worker تجريبي منفصل خلف Cloudflare Access وسياسة مستخدمين مصرح لهم وحد للطلبات قبل الوصول إليه، ثم تعيين إعداد التشغيل والمفتاح في أسرار Cloudflare فقط، وضبط مسار محمي ومراجعة عدم تسجيل المفتاح في السجلات. إعداد trace مفعّل للتجربة المقيدة؛ يجب التحقق من حدود الخدمة المجانية وتجنب أي إعداد مدفوع أو يتطلب بطاقة. تُقاس أزمنة CPU وحالات تجاوز الحد ونجاح الطلبات من لوحة Cloudflare، باستخدام بيانات وهمية فقط، ثم يُعطّل العامل بعد القياس. لا تنسخ مفتاحاً هنا ولا تُرسله في المحادثة. نتيجة نموذج الذاكرة وحده لا تثبت ملاءمة العمليات النهائية أو أداء Neon؛ يلزم قياس الدخول، وإعادة الضبط، وفحص الجلسة بالربط الفعلي عندما يكون جاهزاً.

لا نملك اتصالاً بحساب Cloudflare من هذه الجلسة، ولم ننشر مختبر القياس؛ لذا **لا توجد قراءة CPU فعلية ولا قرار نهائي بملاءمة الخطة المجانية**. إذا تبيّن عدم ملاءمتها نقيّم Netlify المجاني كما وافق صاحب المشروع، دون ترقية مدفوعة.

## تحقق قابل للتكرار

`npm run build`، و`npm test`، و`npm run test:postgres-lab` على قاعدة PostgreSQL محلية معزولة، و`npm audit --audit-level=high`. تفاصيل إعداد القاعدة التجريبية في `experiments/postgres-auth-lab/README.md`. الاختبار المحلي لا يتصل بـ Neon.
