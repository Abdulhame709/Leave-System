# مساحة الإجازات — نسخة تأسيسية

واجهة تجريبية عربية لتوضيح فكرة نظام الإجازات وخطوة تأكيد إدخال الطلب في أونكس. **ليست جاهزة للعمل الفعلي**: المثال لا يحفظ أي شيء، ولا يوجد تسجيل دخول أو قاعدة بيانات أو اتصال بأونكس، ولا حماية مؤسسات بعد. لا تُدخل بيانات حقيقية.

## التشغيل على جهاز التطوير

يجب تثبيت Node.js 22 أو أحدث. من مجلد المشروع:

```sh
npm install
npm run dev
```

افتح العنوان الذي يظهر في الطرفية. إيقاف التشغيل باستخدام Ctrl+C.

للتحقق من البناء والاختبارات:

```sh
npm run build
npm test
```

الاختبارات الموجودة تخص المثال المحلي فقط؛ لا تثبت أمان النظام ولا اختبارات الأرصدة أو العزل. تفاصيل الخطة في `PROJECT_SPEC.md` و`DECISIONS.md` و`docs/phase-0-proposal-ar.md`.

أُضيف مخطط أولي لقاعدة البيانات واختبارات عزل جزئية؛ لم يُربط التطبيق بقاعدة بيانات بعد. تفاصيل الاختبارات وحدودها في `docs/database-foundation-ar.md`.

تفاصيل إعداد قاعدة Neon للتطوير واختبارها في `docs/neon-dev-setup-ar.md`. نجح اختبار اتصال القاعدة، لكن التطبيق ليس مرتبطاً بها بعد.

المرحلة الأولى قيد التنفيذ؛ تفاصيل قواعد الصلاحية الأولية والنواقص في `docs/phase-1-ar.md`.

نُشرت نقطة فحص أولية لخادم التطوير `leave-system-api-dev`، وتأكد صاحب المشروع أنها تستجيب. لا اتصال بين الخادم وقاعدة البيانات ولا تسجيل دخول حتى الآن.

نجحت اختبارات قواعد قراءة العضويات لمؤسستين على Neon للتطوير. لا يُعد ذلك تسجيل دخول أو ربطاً بالتطبيق أو ترخيصاً باستخدام بيانات حقيقية.
